# 영어 끝말잇기 챌린지 (Word Chain Challenge)

중학교 2학년 EFL 학생용 영어 끝말잇기 웹앱. 학생 vs 컴퓨터.

## 구조
- `app.html` — 앱 본체(HTML/CSS/JS). `/*__VOCAB__*/` 자리에 단어장·영어 단어 목록이 들어감. 맨 위 `SETTINGS`에 선생님이 바꿀 수 있는 설정을 모아 둠
- `vocab.js` — 단어장
  - `VOCAB_E` 초등 권장 수준(대명사 격변화, 비교급·최상급, 기본 단어 포함)
  - `VOCAB_M` 중학교 수준
  - `VOCAB_TB` 중학교에서 자주 쓰는 단어 보충
  - `VOCAB_CORE` 교육부 영어과 교육과정 기본 어휘 level 1(`*` 초등 권장, 초등 수준) 840개 · level 2(`**` 중학교, 중학 수준) 1,279개(괄호 안 파생어 포함). 위 단어장에 이미 있는 단어는 단어만 적고 그 뜻을 씀(뜻은 한 곳에만), 없는 659개는 새로 쓴 사전식 뜻. `tools/make-core-vocab.py`로 만듦(직접 고치지 않음)
  - `VOCAB_CORE_ACCEPT` 학생 답으로만 인정하는 기본 어휘 973개: level 3(표시 없음, 고등학교 수준), 빗금으로 나뉜 다른 철자(colour, aeroplane …), 출제에서 뺀 단어(술·담배·폭력·성 관련 등). 뜻이 없어 "📗 단어장 밖 단어"로 인정. 컴퓨터 출제·힌트·예시·객관식 보기·기초 문제·단어 수첩 복습, 기본 어휘 가중치·보너스에는 쓰지 않음
  - `VOCAB_NUM` 수 단어(one~twenty, thirty~ninety, hundred, thousand) — 학생 답으로만 인정, 컴퓨터는 내지 않음
  - `VOCAB_WF_E`·`VOCAB_WF_M` 접미사로 만든 단어(동사+er/r 사람·도구, 명사+al, 명사+y/ly, 형용사+ly, 동사+ment, 형용사+ness) — 뜻 뒤에 `(sing+er)`처럼 원래 단어 표시
  - `EMOJI` 그림 단어
- `wordlist.js` — 영어 단어 목록 79,200개(SCOWL size 60, 미국식 철자, 소문자 알파벳 단어만, 욕설·비속어 제외). 단어장 밖 단어가 올바른 영어 단어인지 판정. `tools/make-wordlist.py`로 다시 만들 수 있음
- `blocklist.js` — 부적절한 단어 목록(영어 욕설·성적 어휘·혐오 표현, 한국어 욕설의 로마자·영문 자판 표기). base64로 인코딩해 페이지 소스에서 바로 읽히지 않고 실행할 때 풂. `tools/blocklist.py`로 관리
- `build.py` — `dist/wordchain.html`(claude.ai 아티팩트용, doctype 없음)과 `dist/word-chain-challenge.html`(학생 배포용 단독 HTML) 생성. 화면 아래 `버전`에 빌드 시각(한국 시간)을 넣음. 빌드할 때 영어 단어 목록에서 금지어를 모두 뺌
- `tests/` — Playwright 테스트. 모두 소리 없이 실행(`tests/lib.js`가 단어 읽기를 끄고 음소거)
  - `play-test.js` 도전 2단계 40턴, "이미 나온 단어" 오판 확인
  - `cpu-rules.js` 컴퓨터 단어 첫=끝 글자·수 단어 금지, 단어장 단어만(level 3·인정 전용 단어 금지) 확인
  - `core-vocab.js` 기본 어휘: 빌드에 예전 단어장 자료(뜻·쪽수·자료 이름) 없음, 기본 어휘 가중치 ×5, level 3는 출제 안 하고 학생 답으로 인정, 기본 어휘 탐험가 배지(예전 배지 유지)·수첩 사유
  - `accept.js 단어…` 학생 답으로 인정되는지 확인
  - `variety.js` 시작 글자 다양성 확인
  - `ime.js` 한글 자판으로 칠 때 글자가 빠지거나 겹치지 않는지 확인(입력기 조합 흉내)
  - `speech.js` 단어 읽기 순서·간격 확인(가짜 음성 엔진, 소리 없음)
  - `judge.js` 단어 판정(단어장 / 단어장 밖 / 틀린 단어)과 철자 도움 확인
  - `basic.js` 기초 4단계(철자 고르기·글자 블록·빈칸 채우기·직접 쓰기), 틀린 보기 규칙, 자동 조절, 건너뛰기 도전, 진도 초기화 확인
  - `listen.js` 듣고 쓰기: 토글, 듣기 챌린지, 다시 듣기, 글자 수, 공개, 끝 글자 설명, 소리 끔 확인
  - `score.js` 콤보·점수·배지: 점수 규칙, 콤보, 축하 효과, 최고 점수, 배지 저장·알림·화면, 통과 요약(쉬어 가기 ①) 확인
  - `blocklist.js` 금지어: 소스에서 안 읽힘, 출력에 없음, 정상 단어가 안 막힘, 입력 시 읽지 않음·기록 안 함·3번째는 평범한 오답
  - `rest.js` 쉬어 가기: 통과 뒤 화면, 정답률·시간, 이번에 얻은 배지만, 미니 복습 단어 순서, 정식 복습/연습 도장 차이, 상자 보상·보관 힌트가 가득 찼을 때 대체, 건너뛰기, 다음 단계 시작(Enter), 마지막 단계 수준 정복
  - `lives.js` 하트: 틀리면 하트 1개·성공 수 유지, 하트를 다 잃으면 처음부터, 목표를 채우면 통과, 단계 목표·문구, 진행 쉼(약 2초), 예전 진도 유지, 기초는 예전 방식
  - `hints.js` 보관 힌트: 무료 힌트 먼저, 단계 이동 후 유지, 다른 수준으로 안 옮겨짐, 보관 한도, 한 번 도전당 사용 제한, 기록 지우기
  - `shop.js` 수첩 안내·지금 연습하기(도장·날짜 그대로)·수첩 단어 보너스, 별 적립·차감·부족 시 비활성·최대 구매 횟수·다시 듣기·시간 사기
  - `levels.js` 수준별 1·2단계를 정답으로 자동 플레이해 통과·오류 확인
  - `notebook.js` 단어 수첩: 오늘의 복습, 도장·복습 간격, 외운 단어, 수첩 비우기, 단어 모으기 확인
  - 앞에 주소를 주면 그 주소(예: GitHub Pages)를, 없으면 로컬 빌드를 테스트
- `tools/blocklist.py` — 금지어 목록 보기·추가·삭제·확인
- `tools/add-words.js` — 단어 확인(`check 단어…`)·추가(`add 파일.txt`, 이미 있는 단어는 건너뜀)
- `tools/extract-curriculum.py` — 기본 어휘 PDF(`data/basic-vocab.pdf`) → `data/curriculum-vocab.json`(`{word, forms, level, raw}`)과 `data/extract-report.md`(개수·검증). `pdftotext -raw` 사용, 글자가 없는 쪽이 있으면 멈춤(OCR 안 함)
- `tools/make-core-vocab.py` — `data/curriculum-vocab.json` + `data/new-meanings-review.tsv`(새로 쓴 뜻: 단어·뜻·level) → `vocab.js`의 `VOCAB_CORE`·`VOCAB_CORE_ACCEPT`, 보고서 끝 '단어장 반영' 절. 뜻을 고치려면 TSV를 고치고 이 스크립트 → `python build.py`
- `data/` — 기본 어휘 원본 PDF, 추출 결과, 보고서, 새 뜻 검토 파일
- `private/` — 저장소에 올리지 않는 자료(`.gitignore`). `private/old-vocab.js`: 예전 단어장 보관본 — 앱·빌드에서 쓰지 않음(`tests/core-vocab.js`가 있으면 빌드에 그 뜻이 없는지 비교, `tools/make-core-vocab.py`는 비교 결과를 `private/old-vocab-report.md`에만 씀)
- `.claude/skills/` — Claude Code용 skill: `wordchain-test`, `wordchain-deploy`("완료배포"), `wordchain-add-words`
- `old/` — 이전 버전

## 빌드 / 테스트

```
node tests/play-test.js
node tests/cpu-rules.js
```
필요: Python 3.12, Node.js LTS, `npm i -g playwright` + `npx playwright install chromium`. Git Bash의 PATH·NODE_PATH는 `~/.bashrc`에 설정.

## 게임 규칙 요약
- 첫 화면에서 수준 선택: 기초(4단계) / 보통(4단계) / 도전(5단계, 모두 주관식)
- 보통 1단계도 기초 3단계처럼 '빈칸 채우기'(다음 단어의 뜻·소리를 보고 빈칸 칸에 글자를 씀, 첫 글자는 항상 빈칸, 잘할수록 빈칸이 늘어남, 4~8글자)
- 기초 수준(1~3단계): 앱이 '다음에 올 단어'(컴퓨터 단어의 끝 글자로 시작하는 단어장 단어)를 정해 뜻·그림·소리를 보여 주고, 학생은 그 철자를 완성. 끝말잇기 줄은 그대로 이어짐
  - 1단계 철자 고르기(연속 4): 정답 1개 + 철자만 틀린 보기 2~3개. 틀린 보기는 모음 바꾸기·끝 e 빼기/붙이기·겹자음 빼기/넣기·이웃 글자 순서 바꾸기로 만들고, 서로 겹치거나 실제 영어 단어가 되면 뺌. 숫자 키 1~4로도 고름
  - 2단계 글자 블록 조립(연속 5): 첫 글자는 놓여 있고 섞인 글자 블록을 눌러 완성. 키보드로 글자를 쳐도 됨(한글 자판이어도 자판 위치로), Backspace·↶ 되돌리기(글자 블록 상자 안내 줄)
  - 3단계 빈칸 채우기(연속 5): 점선 빈칸 칸에 바로 글자를 씀(한 칸 채우면 다음 빈칸, Backspace로 앞 빈칸, Enter로 확인). 빈칸은 항상 2칸 이상이고 그중 하나는 첫 글자(컴퓨터 단어의 끝 글자): 처음 첫 글자 + 1칸, 자동 조절로 첫 글자 + 2칸 … 최대 단어 길이의 절반. 첫 글자를 틀리면 "컴퓨터 단어의 끝 글자를 다시 봐요."(다음 칸으로 넘어가지 않음), 맞으면 연결선이 이어짐. 힌트는 첫 글자가 아닌 빈칸부터 채우고 첫 글자 빈칸은 끝까지 직접. 글자 칸은 단어 길이에 맞춰 항상 한 줄
  - 끝 글자–첫 글자 연결 표시(1~3단계): 컴퓨터 단어의 끝 글자와 다음 단어의 첫 글자(1단계 보기의 첫 글자, 2단계 첫 칸, 3단계 첫 빈칸)를 같은 주황색으로 강조. 넓은 화면(600px 이상)은 오른쪽 여백·카드 사이로 꺾인 선으로 이음 — 3단계는 첫 글자를 맞게 채우기 전까지 점선, 맞으면 실선으로 이어지는 짧은 효과. 휴대폰(좁은 화면)은 선 대신 새 단어마다 끝 글자가 첫 글자 자리로 한 번 건너가고(1단계는 보기마다, 3단계는 답을 대신 채우지 않게 글자 없이 동그라미) 닿은 칸이 반짝임, 3단계 첫 글자를 맞히면 끝 글자와 첫 칸이 함께 반짝임. 동작 줄이기 설정이면 효과는 생략
  - 4단계 직접 쓰기(연속 6): 예전 기초 직접 쓰기와 같음(2글자 이상)
  - 자동 조절: 같은 단계에서 3연속 정답이면 한 칸 어렵게, 2연속 오답이면 한 칸 쉽게(1단계 보기 수, 2단계 헷갈리는 글자 블록 수, 3단계 빈칸 수: 첫 글자 + 1~3칸). 상태 줄에 '난이도 N ▲/▼'. `SETTINGS.adapt`
  - 힌트(3번)는 '한 글자 더 보여 주기'
  - 건너뛰기 도전: 기초 1단계를 처음 할 때 힌트·실수 없이 통과하면 쉬어 가기 ① 화면에 '3단계로 바로 가기'(1·2단계 통과 처리). 필요한 연속 수는 `SETTINGS.skipStreak`(기본 5, 1단계 목표 4보다 크면 목표 수)
  - 기초를 4단계로 바꾸면서 예전 기초 진도만 한 번 초기화(다른 수준 진도는 유지)
- 단계 목표: 기초 연속 4·5·5·6(틀리면 연속 기록 0), 보통 5·6·7·8, 도전 6·7·8·8·6(듣기 챌린지 6)
- 보통·도전은 하트 방식(`SETTINGS.lives`, 기본 3, 0이면 기초처럼 틀리면 연속 기록 0): ❤️ 3개로 시작, 틀리거나·이미 나온 단어·시간 초과·금지어 3번째면 하트 1개를 잃고 성공 수는 그대로. 하트를 다 잃기 전에 목표 수만큼 성공하면 통과, 하트를 다 잃으면 성공 0·하트 3개로 다시. 상태 줄에 "성공 N / 목표 ❤️❤️🤍". 콤보와 콤보 기준 배지(불꽃·다시 일어서기)는 틀리면 0부터
- 정답 뒤 컴퓨터가 다음 단어를 내기까지(`SETTINGS.pace`): 모든 수준에서 학생 단어를 읽고 1초 쉰 뒤, 답한 뒤 최소 2초
- 목표를 바꿔도 예전 진도(통과·열린 단계)는 그대로. 힌트는 한 도전에 3번
- 컴퓨터 단어 길이는 단계의 `cpuMin`/`cpuMax`로 조절
- 규칙 변화 비교급·최상급(bigger, happiest 등)은 학생 답으로는 인정, 컴퓨터 출제·보기·힌트에는 쓰지 않음 (better/best 등 불규칙은 출제 가능)
- y로 끝나는 단어는 컴퓨터 출제 빈도 1/4
- 컴퓨터는 첫 글자와 끝 글자가 같은 단어(dad, trust 등)는 내지 않음
- 학생이 시작할 글자가 겹치지 않도록, 컴퓨터는 최근 두 번 요구한 글자로 끝나는 단어를 피함(다른 후보가 없을 때만 허용)
- 컴퓨터는 끝 글자를 먼저 고르게 뽑은 뒤 그 글자로 끝나는 단어를 고름 → b·p·f처럼 드문 글자로도 시작하게 됨
- 스피드 챌린지 기본 제한 시간: 보통 30초 · 도전 25초. 홈 화면과 게임 화면의 −5초/+5초 버튼으로 10~90초 조절(수준·단계별 저장). 게임 중 늘리기는 바로, 줄이기는 다음 단어부터 적용
- 휴대폰 화면 키보드: 키보드가 올라오면(보이는 높이가 120px 넘게 줄면, `visualViewport`) 게임 화면을 줄여(끝말잇기 줄·그림·설명 글·시간 조절·듣고 쓰기 토글 숨김, 컴퓨터 단어 카드 한 줄) 맨 위부터 입력칸까지 키보드 위에 보이게 하고, 브라우저가 입력칸을 보이려고 화면을 밀어 올린 것을 되돌림. 아주 작은 화면은 컴퓨터 단어 카드가 보이는 데까지만 올리고 입력칸은 늘 보임. 키보드가 내려가면 맨 위로. 안드로이드 크롬은 `interactive-widget=resizes-content`
- 영문 입력: 휴대폰은 `inputmode="email"`로 영문 자판이 뜸. PC에서 한글 자판으로 치면 같은 자리의 영문 글자로 자동 변환(두벌식 기준, 메ㅔㅣㄷ → apple)
- 기본 어휘 우선: 컴퓨터 출제·객관식 정답·기초 다음 단어·힌트·예시·철자 도움에서 교육부 기본 어휘 level 1·2 단어 5배 가중치(`SETTINGS.coreWeight`). level 3·인정 전용 단어는 출제하지 않음. 기본 어휘 level 1 단어는 기존 단어장에서 중학 수준이었어도 초등 수준(기초 수준에서도 나옴)으로 봄
- 단어 판정(주관식): ① 단어장 단어 → 정답, 뜻 표시 ② 단어장엔 없지만 영어 단어 목록(변화형 포함)에 있음 → 정답, "📗 단어장 밖 단어"(뜻 없음), 컴퓨터가 끝 글자로 이어 감 ③ 둘 다 없음 → 같은 첫 글자·철자 차이 1~2인 단어장 단어를 최대 3개 보여 주고(누를 수 없고 직접 다시 써야 함) 1번 더 기회, 두 번째도 틀리면 오답. 다시 쓸 기회 수는 `SETTINGS.wrongRetry`(0이면 바로 오답)
- 듣고 쓰기: 컴퓨터 단어를 화면에 보여 주지 않고 소리로만 들려줌. 학생은 들은 단어의 끝 글자로 시작하는 단어를 씀. 답을 내면(정답·오답 모두) 컴퓨터 단어를 공개하고, 끝 글자를 놓친 이유가 소리 나지 않는 끝 글자(끝의 묵음 e, -y[이], -le, -gh)이면 짧게 설명
  - 보통 2~4단계: "🎧 듣고 쓰기" 토글(다음 단어부터 적용, 다시 듣기 2번, 글자 수 □ 표시). 켜고 끈 상태는 저장됨
  - 도전 5단계 "듣기 챌린지": 4단계를 통과해야 열림, 6번 성공 목표(하트 3개), 다시 듣기 1번, 글자 수 표시 없음, 소리를 끌 수 없음
  - 답을 낸 뒤 공개한 컴퓨터 단어를 3초 더 보여 준 다음 학생 단어의 끝 글자로 이어 감(`SETTINGS.listen.revealHold`)
  - 듣고 쓰기 중 힌트는 시작 글자 대신 끝소리 단서: ① 천천히 들려주기(🐢 다시 듣기 가능)+글자 수 ② 뜻 ③ 끝 글자만 가린 철자(예: s a t i s f _ ) — satisfy/satisfied처럼 끝소리가 비슷한 단어 구별용
  - 소리 읽기(speechSynthesis)가 안 되는 브라우저에서는 토글이 비활성화되고 이유를 표시(듣기 챌린지는 단어를 보여 줌). 소리를 끄면 듣고 쓰기를 켤 수 없음. 다시 듣기 횟수는 `SETTINGS.listen`
- 나의 단어 수첩(꺼내 쓰기·간격 복습): 틀렸을 때 나온 정답 예시, 힌트로 본 단어, 처음 맞힌 기본 어휘(level 1·2)를 자동으로 모음. 처음 모은 다음 날 복습 → 맞히면 3일 → 7일 뒤, 틀리면 다음 날로 되돌림, 도장 3개면 '외운 단어'. 복습할 단어가 있으면 첫 화면·단계 목록에 "오늘의 복습 N개" 버튼(강제 아님). 복습은 뜻(그림)과 소리를 보고 듣고 철자를 직접 씀, 기초 수준이면 빈칸 채우기 형태(t _ g _ r). 단계 목록의 "📒 단어 수첩"에서 모은 단어·뜻·도장·외운 단어를 보고, "수첩 비우기"(두 번 눌러 확인). 간격은 `SETTINGS.review`
  - 수첩 화면 위 안내: "모은 단어는 다음 날부터 '오늘의 복습'에 다시 나와요. 맞히면 도장을 받고, 도장 3개를 모으면 '외운 단어'가 돼요." 다음 복습 날짜는 오늘/내일/10/18처럼 표시
  - "✏️ 지금 연습하기": 복습 날짜가 안 된 단어도 포함해 수첩 단어(외운 단어 제외)를 섞어 최대 10개 연습(`SETTINGS.practiceMax`). 방식은 오늘의 복습과 같고, 도장·복습 날짜·외운 단어는 바꾸지 않음
  - 끝말잇기 중 수첩 단어(외운 단어 제외)를 정답으로 쓰면 "📒 수첩 단어!"와 보너스 +5점(`SETTINGS.score.notebookBonus`, 힌트 쓴 턴은 제외). 도장·날짜는 그대로
- 콤보·점수·배지(동기 부여용, 단계 통과 조건은 그대로)
  - 콤보: 연속 성공 3번부터 "🔥 3콤보" 표시, 5·10콤보에서 짧은 축하 효과(동작 줄이기 설정이면 생략). 틀리면 0, 단어 목록에 없어 다시 쓰는 경우는 유지
  - 점수(한 판, 감점 없음): 정답 10 + 길이 보너스(5글자 이상 (글자 수 − 4) × 2) + 기본 어휘 보너스(level 2 +5, level 1 +3) + 단어장 밖 단어 +3, 콤보 배율(3~4 ×1.2, 5~9 ×1.5, 10 이상 ×2, 소수점 버림), 듣고 쓰기 ×1.5. 힌트를 쓴 턴은 길이·기본 어휘 보너스만 없어짐. 화면 위에 현재 점수, 단계 목록에 이 단계 최고 점수
  - 배지 14개: 첫걸음, 불꽃 5/10, 긴 단어(7글자 이상), 기본 어휘 탐험가 10/30(서로 다른 기본 어휘 level 1·2 단어, 누적. 배지 id `tb10`·`tb30`은 예전 그대로라 이미 얻은 배지 유지), 사전 밖 모험가(단어장 밖 단어 5개, 누적), 힌트 없이(단계 통과), 다시 일어서기(틀린 뒤 5콤보), 복습왕(외운 단어 10개), 귀가 밝아요(듣고 쓰기 5연속), 기초·보통·도전 정복. 처음 얻으면 화면 아래 3초 알림, 단계 목록 "🏅 배지"에서 얻은 배지와 못 얻은 배지(조건, 흐리게)를 봄
  - 단계 통과 요약(쉬어 가기 ①)에 이번 판 점수·최고 콤보·이번에 얻은 배지
  - 점수 값은 `SETTINGS.score`, 콤보는 `SETTINGS.combo`, 배지 조건 숫자는 `SETTINGS.badge`
- 부적절한 단어 차단
  - 판정 순서: 단어장 단어면 항상 허용 → 금지어 확인 → 단어장 밖 판정 → 철자 도움
  - 비교는 대소문자 무시, 같은 글자 3번 이상 반복은 2번으로 줄임(일부러 늘여 쓴 입력은 1번으로 줄인 형태도 비교). 정확히 같은 금지어는 항상, 강한 표현은 단어장 밖 입력 안에 들어 있기만 해도 막음(class, grape, assistant, saltwater 같은 정상 단어는 테스트로 확인)
  - 금지어를 쓰면 소리로 읽지 않고, 단어를 다시 보여 주지 않고, 입력 칸을 비운 뒤 "다른 단어를 써 보세요."만 평범한 안내와 같은 모양으로 표시(어떤 단어가 막히는지 시험하는 놀이가 되지 않게 특별한 반응을 보이지 않음). 정답·점수·콤보·배지·단어 수첩·연속 기록에 반영하지 않음. 한 판에서 3번째면 이유 설명 없이 평범한 오답 화면과 함께 다른 오답과 똑같이 처리(보통·도전은 하트 1개, 기초는 "아쉬워요! 새 판으로 다시 도전해요."와 연속 기록 0), 새 판. 입력 내용·횟수는 저장하지 않음
  - 컴퓨터 출제·힌트·예시·객관식 보기·듣고 쓰기·단어 수첩 복습·철자 도움에는 금지어가 나오지 않음
- 별 모으기·힌트 사기
  - 한 판이 끝날 때(오답으로 새 판, 단계 통과, 단계 목록으로 나갈 때) 그 판에서 얻은 점수를 별로 바꿔 모음: 10점 = ⭐1, 소수점 버림(남은 점수는 같은 단계 도전 안에서 이어짐). 모든 수준이 같은 별을 씀. 화면 위(점수 옆)·단계 목록에 "⭐ N", 단계 통과·오답 화면에 "이번 판에서 ⭐ +N"
  - 무료 힌트: 도전(단계 시작)마다 3번을 새로 주고 쌓이지 않음
  - 보관 힌트: 무료 힌트를 다 쓰면 "⭐ 보관 힌트 사기" → 펼친 줄에서 −/+로 개수를 고르고 한 번 더 눌러 확인(확인 창 없음). 1개에 ⭐5
    - 수준(기초·보통·도전)별로 따로 저장. 같은 수준에서는 단계가 바뀌거나 새 판이 되어도 남고, 다른 수준으로는 옮겨지지 않음
    - 수준별 최대 5개 보관. 가득 차면 사기 버튼 비활성 + "보관 힌트가 가득 찼어요 (5/5)". 별이 모자라면 비활성 + "별이 부족해요 (⭐ 2/5)"
    - 사용 순서: 무료 힌트 → 보관 힌트. 한 번 도전에 보관 힌트는 2번까지
    - 힌트 표시는 "무료 💡 2 · 보관 💡 3", 단계 목록에 현재 수준의 "💡 보관 힌트 N/5"와 안내. 힌트를 쓴 턴은 보너스 점수 없음
    - "이 수준 기록 지우기"를 하면 그 수준의 보관 힌트도 지워짐(별은 그대로)
  - 듣고 쓰기 "다시 듣기 +1" ⭐3(다시 듣기를 다 쓰면 나타남), 시간 제한 단계 "시간 +10초" ⭐3 — 각각 한 판에 1번
  - 금지어 입력·오답·단어장 밖 다시 쓰기로는 별이 줄지 않음. 값은 `SETTINGS.shop`
- 키보드만으로 조작: 모든 버튼은 Tab·Enter, 객관식·철자 고르기는 숫자 키 1~4, 글자 블록은 글자 키·Backspace
- 진행 기록과 제한 시간 설정은 브라우저 localStorage(`wordchain-v2`)에 수준별로 저장
- 쉬어 가기(단계 통과 뒤, 다음 단계 전 · 1분 안쪽): 예전 🏆 통과 창을 대신함. 위쪽에 ① 통과 · ② 복습·상자 · ③ 다음 단계 표시, 단계마다 주요 버튼에 초점이 가서 Enter만으로 진행
  - ① 통과 요약: 이번 단계에서 받은 ⭐, 정답률(맞힌 턴 / 답을 낸 턴 — 금지어 입력과 '단어장에 없어 다시 쓰기'는 세지 않음), 걸린 시간(단계 시작부터 통과까지, "2분 35초"), 이번 판 점수·최고 콤보, 이번에 새로 얻은 배지만. 힌트 없이 통과하면 "✨ 힌트 없이 통과!"(동작 줄이기 설정이면 반짝임 생략). '이 단계 더 연습', 기초 1단계 건너뛰기 버튼도 여기에
  - ② 미니 복습 → 🎁 상자: 단어 수첩에서 최대 2개 — 복습 날짜가 된 단어 → 날짜가 안 된 수첩 단어(외운 단어 제외) → 수첩이 비었으면 방금 끝낸 끝말잇기 줄에서 내가 쓴 단어(단어장 단어만), 금지어 제외. 오늘의 복습과 같은 방식(뜻·그림·소리를 보고 철자 쓰기, 기초는 빈칸 형태). 날짜가 된 단어만 정식 복습(맞히면 도장 +1, 틀리면 도장 0·다음 날), 나머지는 연습(도장·날짜 그대로). 틀려도 정답을 보여 주고 넘어감. 다 하면 "🎁 상자 열기" → 짧은 열림 효과(동작 줄이기면 생략)와 보상 하나: ⭐1(50%) · ⭐2(30%) · ⭐3(10%) · 보관 힌트 1개(10%, 가득 찼거나 보관 기능이 없으면 ⭐3). 미니 복습을 모두 맞히면 ⭐ +1 더. "건너뛰기"는 언제나 있고 누르면 상자 없이 ③으로. 값은 `SETTINGS.restBox`
  - ③ 🤖 컴퓨터의 한마디: 다음 단계에 맞는 말풍선(수준·단계별 2~3개 중 무작위) + 다음 단계 이름·방식 한 줄 + "▶ N단계 시작"(Enter)·"단계 목록으로". 문구는 app.html 위쪽 `REST_LINES`('수준-다음 단계 번호', 없으면 time·listen·other)에서 고침
  - 수준의 마지막 단계면 ①·② 뒤에 ③ 대신 "🎉 ○○ 수준 정복!"과 수준 선택 버튼
- 배지 알림은 여러 개를 한꺼번에 얻으면 위로 쌓여 보임

## 설정값 위치
`app.html` 스크립트 맨 위 `SETTINGS` 객체에 모여 있다. 숫자만 바꾸고 `python build.py`.
| 설정 | 내용 | 기본값 |
|---|---|---|
| `wrongRetry` | 틀린 단어에 다시 쓸 기회(0이면 바로 오답) | 1 |
| `suggestMax` · `suggestDist` | 철자 도움 단어 수 · 허용 글자 차이 | 3 · 2 |
| `review.intervals` · `review.stampsToLearn` | 복습 간격(일) · 외운 단어가 되는 도장 수 | [1,3,7] · 3 |
| `adapt.upAfter` · `adapt.downAfter` | 기초 자동 조절: 연속 정답/오답 횟수 | 3 · 2 |
| `skipStreak` | 건너뛰기 도전에 필요한 연속 성공(1단계 목표보다 크면 목표 수) | 5 |
| `listen.normalReplays` · `listen.hardReplays` | 듣고 쓰기 다시 듣기 횟수(보통 · 듣기 챌린지) | 2 · 1 |
| `listen.revealHold` · `listen.slowRate` | 답을 낸 뒤 공개한 컴퓨터 단어를 보여 주는 여유(ms) · 듣기 힌트의 천천히 듣기 속도 | 3000 · 0.45 |
| `basicSpeech.rate` · `basicSpeech.targetGap` | 기초 수준 읽기 속도 · 컴퓨터 단어를 읽고 다음 단어를 읽기까지 쉬는 시간(ms) | 0.6 · 1500 |
| `score` | 점수 기본·보너스(수첩 단어 `notebookBonus` 포함)·콤보 배율·듣고 쓰기 배율 | 위 규칙 |
| `shop` | 별: `pointsPerStar`(점수→별), `hintPrice`(보관 힌트 1개 가격), `maxStored`(수준별 보관 한도), `maxUsePerRun`(한 번 도전에 쓸 수 있는 보관 힌트 수), `replayPrice`·`timePrice`·`timeAdd` | 10, 5, 5, 2, 3, 3, 10 |
| `practiceMax` | 지금 연습하기 한 번에 낼 단어 수 | 10 |
| `restBox` | 쉬어 가기: `words`(미니 복습 단어 수), `rewards`(상자 보상 확률 p%와 ⭐ 수/보관 힌트), `fullHintStars`(보관 힌트 대신 줄 별), `perfectBonus`(미니 복습 모두 맞힘 보너스) | 2, ⭐1 50%·⭐2 30%·⭐3 10%·힌트 10%, 3, 1 |
| `REST_LINES` (SETTINGS 아래) | 쉬어 가기 ③ 컴퓨터의 한마디 문구 | 수준·단계별 2~3개 |
| `lives` | 보통·도전 하트 수(0이면 틀리면 연속 기록 0) | 3 |
| `pace.<수준>.after` · `pace.<수준>.gap` | 정답 뒤 학생 단어를 읽고 쉬는 시간 · 다음 컴퓨터 단어까지 최소 시간(ms) | 모든 수준 1000 · 2000 |
| `combo.show` · `combo.celebrate` | 콤보 표시 시작 · 축하 효과 | 3 · [5,10] |
| `coreWeight` | 기본 어휘 level 1·2 우선 출제 배수 | 5 |
| `badge` | 배지 조건 숫자(`core`: 기본 어휘 탐험가) | 위 규칙 |

단계 구성(목표 수, 글자 수, 제한 시간 등)은 같은 파일의 `TRACKS`, 읽기 속도·흐름 여유는 `SPEECH_RATE` 등.

## localStorage 키 (학생 기기에만 저장, 개인 정보 없음)
| 키 | 저장 내용 |
|---|---|
| `wordchain-v2` | 마지막 수준(`track`), 수준별 진도 `prog.{basic,normal,hard}` = `{unlocked, best(단계별 최고 연속·성공 수), cleared, bestScore(단계별 최고 점수), storedHints(그 수준의 보관 힌트 개수)}`, 제한 시간 설정 `time`, 듣고 쓰기 토글 `listen`, 배지용 누적 기록 `stats = {tb: 맞힌 기본 어휘(키 이름은 예전 그대로), outside: 단어장 밖 단어 수}`, 기초 구성 버전 `basicVer` |
| `wordchain-notebook-v1` | 단어 수첩 `items = {단어: {w, reason, stamps, due}}`, 외운 단어 `learned = {단어: {w, date}}`, 처음 맞힌 기본 어휘 `tbSeen`(키 이름은 예전 그대로, 수첩 사유 키 `textbook`도 그대로 두고 화면에는 "처음 맞힌 기본 어휘") |
| `wordchain-badges-v1` | 얻은 배지 `[{id, date}]` |
| `wordchain-stars-v1` | 모은 별 개수(숫자 하나). 기기에 저장되므로 공용 기기(교실 크롬북 등)에서는 다른 학생이 모은 별을 쓸 수 있음 |

이름·학번·목소리 등은 받거나 저장하지 않는다. 음성 인식은 쓰지 않고 음성 합성(speechSynthesis)만 쓴다.

## 금지어 목록 고치기 (선생님용)
목록은 `blocklist.js`에 인코딩되어 있어 직접 열어 고치지 않고 명령으로 고친다. 고친 뒤에는 `python build.py`로 다시 빌드한다.
```
python tools/blocklist.py show                    # 목록 보기
python tools/blocklist.py add 단어 단어            # 정확히 같을 때 막는 단어 추가
python tools/blocklist.py add --strong 표현        # 단어장 밖 입력 안에 들어 있기만 해도 막는 강한 표현 추가
python tools/blocklist.py allow 단어               # 강한 표현이 들어 있어도 허용할 정상 단어(예: snigger)
python tools/blocklist.py remove 단어              # 삭제
python tools/blocklist.py check 단어 단어          # 막히는지 확인
```
- 강한 표현은 정상 단어 안에 들어 있을 수 있으니 추가한 뒤 `node tests/blocklist.js`로 정상 단어가 막히지 않는지 확인한다(예: 'twat'은 saltwater·wristwatch를 막아서 정확히 같을 때만 막도록 둠)
- 단어장(vocab.js)에 있는 단어는 금지어 목록과 관계없이 항상 허용된다. 단어장 단어를 막고 싶으면 단어장에서 지운다

## 단어 출처와 라이선스
### 교육부 영어과 교육과정 기본 어휘
- 출처: 교육부 고시 영어과 교육과정 [별표] 기본 어휘 목록(인쇄 쪽 402~434). 법령·고시 등 공공 문서로 저작권 보호 대상이 아니다(저작권법 제7조)
- 표시 해석(범례 쪽은 원본 PDF에 없음): `*` 초등 권장 어휘 → level 1, `**` 중학교 어휘 → level 2, 표시 없음 → 고등학교 수준 → level 3
- 괄호 안 단어(`act* (actual, interact)`)는 앞 단어의 level을 따르는 파생어로 함께 인정, 빗금 철자(`color* / colour*`)는 미국식을 기본으로 하고 나머지는 학생 답으로만 인정. 띄어쓰기·하이픈이 있는 표현(twenty-first 등)은 끝말잇기 단어에서 뺌. 자세한 개수·처리 내역은 `data/extract-report.md`
- 뜻: 기존 단어장(VOCAB_E·M·TB·NUM·WF)에 있는 단어는 그 뜻, 없는 level 1·2 단어 659개는 새로 쓴 짧은 사전식 뜻(`data/new-meanings-review.tsv`)
