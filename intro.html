알아보는 단어를
쓸 수 있는 단어로

  • 스스로 떠올려 쓰기

    주어진 글자로 시작하는 단어를 떠올려 철자대로 씁니다. 세 수준 모두 이 직접 쓰기 단계로 이어집니다.

  • 기본 어휘의 반복 노출

    교육과정 기본 어휘가 다른 단어보다 5배 자주 나와, 놀이하는 동안 여러 번 보고 듣습니다.

  • 수준에 맞는 출발점

    철자가 약한 학생은 철자 고르기부터, 자신 있는 학생은 직접 쓰기부터 시작합니다.

고르기에서 직접 쓰기로

수준을 골라 1단계부터 시작합니다. 기초는 목표 수만큼 연속으로, 보통·도전은 하트 3개를 다 잃기 전에 목표 수만큼 맞히면 다음 단계가 열립니다.

  1. 철자 고르기
  2. 글자 조립
  3. 빈칸 채우기
  4. 직접 쓰기
  5. 듣고 쓰기

철자를 한 번 더 보게 하는 장치

비슷한 철자 보여 주기

단어장과 영어 단어 목록에 없는 단어를 쓰면, 철자가 비슷한 단어를 보여 주고 한 번 더 쓸 기회를 줍니다.

소리와 다른 끝 글자 설명

컴퓨터 단어를 소리로만 듣고 끝 글자로 이어 씁니다. write의 e처럼 소리 나지 않거나 graph의 ph처럼 소리와 철자가 다른 끝 글자는 답을 낸 뒤 설명해 줍니다.

나의 단어 수첩

틀린 단어와 힌트로 본 단어가 저절로 모입니다. 다시 맞혀 도장 3개를 받으면 외운 단어가 됩니다.

  • 힌트도전마다 3번, 한 글자씩
  • 자동 난이도 조절기초 수준에서 3번 연속 맞히면 어렵게, 2번 연속 틀리면 쉽게
  • 부적절한 단어 차단욕설·비속어에는 "다른 단어를 써 보세요."만 표시
  • 한글 자판 자동 변환한/영 키를 누르지 않아도 영어로 입력
  • 동기 부여콤보·점수·별·배지 14개, 감점 없음
  • 기기PC, 크롬북, 휴대폰 브라우저
  • 개인정보이름·학번·음성을 받지 않고, 기록은 그 기기에만 저장 (공용 기기는 수업 뒤 '기록 지우기')
  • 선생님 모드앱 주소 뒤에 ?teacher=1을 붙이면 모든 단계를 열어 시연
